# Raider Timer

A classroom timer toolkit for Regis Jesuit High School teachers — countdown, stopwatch, and station rotations with multiple visual styles and sound options.

**[Launch Raider Timer →](https://rjedtech.github.io/Raider-Timer/)**

## Modes

- **⏱ Countdown** — Preset buttons (15s to 5min), custom time entry, and saved presets. Pick a visual style and sound, then go.
- **⏱ Stopwatch** — Count up with hundredths of a second. Lap button for tracking splits.
- **🔄 Station Rotation** — Set number of stations, time per station, and transition time between. Auto-advances through all rotations with a progress tracker showing which station you're on.

## Visual Styles

- **🔢 Digital** — Big clean numbers. Color shifts to yellow at 15 seconds and red at 5 seconds.
- **🕐 Analog** — Circular clock face with a sweeping hand and colored progress track.
- **📊 Progress Bar** — Horizontal bar that drains with a percentage readout.
- **⏳ Sand Timer** — Animated hourglass with sand flowing between chambers.

## Sound Options

- **🎵 Jeopardy** — Thinking music that loops while the timer runs.
- **⏰ Game Tick** — Rhythmic ticking that loops while the timer runs.
- **🔔 Chime** — Gentle three-note chime when time is up.
- **📢 Buzz** — Alarm buzz when time is up.
- **🔔 Bell** — School bell pattern when time is up.
- **🔇 Silent** — Visual only, no sound.

## Features

- **Saved Presets** — Name and save custom timers (e.g. "Exit Ticket 5min", "Think-Pair-Share 90s"). One tap to load.
- **Fullscreen Mode** — Fills the projector. Clean display for the classroom.
- **Station Transitions** — Configurable transition time between stations with automatic advancement and audio cues.

## Privacy

- No accounts, no login, no ads, no cookies, no tracking
- No data leaves the browser — everything runs locally
- Saved presets are stored in your browser only
- Nothing is transmitted anywhere, ever

## How to Use

1. Visit the link above and bookmark it
2. Pick a mode: Countdown, Stopwatch, or Station Rotation
3. Choose a visual style and sound
4. Hit Start
